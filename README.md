# Medicine Reminder – Flutter Lab Project

Medicine Reminder application developed according to Experiments 2, 3 and 4 of the UI Design – Flutter Lab manual. Experiment 1 is intentionally omitted.

## Experiment 2 – Widgets and Layouts
Text, Icon, Container, Card, ElevatedButton, Row, Column and Stack are used to build the medicine dashboard.

## Experiment 3 – Responsive UI
MediaQuery, LayoutBuilder, Expanded and SingleChildScrollView are used so the interface adapts to different screen widths.

## Experiment 4 – Navigation
Navigator.push/pop, Named Routes, Drawer-style screen navigation, and passing `MedicineData` to the details screen are implemented.

## Run
```bash
flutter pub get
flutter run
```
